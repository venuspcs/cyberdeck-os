# Raspberry Pi 5

Reserved for a Cyberdeck OS image for the Raspberry Pi 5.

- Architecture: ARM64
- Session: KDE Plasma (Wayland), the same desktop family as the generic image
- This is a board-specific image. It is separate from the generic ARM64 UEFI image under `build/arm64/`
- Boot method (Pi firmware or UEFI): chosen when this image is built, and written down here

This directory is a stub. It does not build a Pi image.

Requirements: [docs/SPEC.md](../../docs/SPEC.md).
