# PineTab2

Reserved for a Cyberdeck OS image for the PineTab2.

- Architecture: ARM64
- Session: Plasma Mobile
- Device support: lean on postmarketOS where it fits
- Boot layout and snapshot rollback: documented here when the image is built, because this tablet does not boot like a PC

This directory is a stub. It does not build or flash a tablet.

Requirements: [docs/SPEC.md](../../docs/SPEC.md).
