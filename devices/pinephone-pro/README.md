# PinePhone Pro

Reserved for a Cyberdeck OS image for the PinePhone Pro.

- Architecture: ARM64
- Session: Plasma Mobile
- Device support: lean on postmarketOS where it fits
- Boot layout and snapshot rollback: documented here when the image is built, because this phone does not boot like a PC

This directory is a stub. It does not build or flash a phone.

Requirements: [docs/SPEC.md](../../docs/SPEC.md).
