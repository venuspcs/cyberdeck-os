# Meshtastic

**Status: written for Beta 1 (Plow).**

`meshtasticd` is installed from the Meshtastic repository configured for Debian 13. Meshtastic Web is one of the Supply Depot containers, published on port 9443 for the local network. MeshCore Web is published on port 9444. Vaultwarden is not installed.
