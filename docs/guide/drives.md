# Drives and `/library`

**Status: stub.** This chapter is not written.

This chapter will cover the Welcome drive choice. On the boot drive, Welcome creates a `/library` folder. On another drive, it offers to format the disk or to use it as-is, then mounts it by UUID in `fstab` and starts Docker only after `/library` is mounted. The chapter will also cover moving `/library` later from the Cyberdeck Control Panel, and the offline map tiles stored under `/library/maps`.

Requirements: [the specification](../SPEC.md), section 8.
