# scripts/

Reserved for maintainer scripts: checksum files for a release, export of the How-To to PDF, ZIM, and ODT, and similar chores around an image that already builds.

**This directory has no scripts.** A helper that calls live-build, Calamares, or Docker would pretend the project can produce an image. Add scripts only after the matching config exists under `build/`, `installer/`, or `firstboot/`.

Requirements: [docs/SPEC.md](../docs/SPEC.md), sections 17 and 18.
