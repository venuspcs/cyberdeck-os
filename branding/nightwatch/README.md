# Nightwatch

Working name for the dark theme.

This directory will hold Nightwatch's wallpaper, boot splash, and login screen. The picture is a rural homestead / off-grid home, and it is a different image from Daybreak.

No artwork is stored here yet. Do not add generated or placeholder art unless a boot path requires a temporary file. That file stays labeled as temporary, as section 14 describes.

Requirements: [docs/SPEC.md](../../docs/SPEC.md), section 14.
