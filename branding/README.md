# branding/

Reserved for Cyberdeck OS branding. Two themes ship with the OS. Daybreak and Nightwatch are the working names.

| Theme | Mode | Art this directory will hold |
| --- | --- | --- |
| [Daybreak](daybreak/README.md) | Light | Its own wallpaper, boot splash, and login screen: a rural homestead / off-grid home |
| [Nightwatch](nightwatch/README.md) | Dark | Its own wallpaper, boot splash, and login screen: a different rural homestead / off-grid home |

The boot splash and the login screen follow the theme that is in effect, including when automatic sunrise/sunset switching has selected it. The logo is one shared mark for both themes and will live in this directory, next to these READMEs.

Artwork is not in this pass. Do not commit stand-in images, generated logos, or third-party art. When a boot path later requires a file before the real art exists, that file stays temporary and labeled, as the spec describes.

Red night-vision and high-contrast sunlight mode are display filters, not extra themes, and they have no artwork here.

This directory has no image files.

Requirements: [docs/SPEC.md](../docs/SPEC.md), section 14.
