# build/arm64/

Reserved for the generic ARM64 UEFI image: one image for laptops, desktops, and boards that boot UEFI, with KDE Plasma on Wayland.

This is not a phone or tablet image, not the Raspberry Pi 5 image, and not an Apple Silicon image. Device images live under [devices/](../../devices/README.md).

This directory is a planning stub. It contains no image configuration and cannot produce a disk image.

Requirements: [docs/SPEC.md](../../docs/SPEC.md). Milestone: [docs/ROADMAP.md](../../docs/ROADMAP.md), milestone 2.
