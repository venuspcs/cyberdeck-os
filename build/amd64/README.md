# build/amd64/

Reserved for the Debian live-build configuration of the AMD64 live and installer ISO.

The config will describe a Debian 13 system with the backported kernel, KDE Plasma on Wayland, the package set in the spec, Calamares, and the first-boot Nomad path. It is not written yet.

This directory is a planning stub. It contains no live-build files and cannot produce an ISO.

Requirements: [docs/SPEC.md](../../docs/SPEC.md). Milestone: [docs/ROADMAP.md](../../docs/ROADMAP.md), milestone 1.
