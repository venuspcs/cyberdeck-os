# control-panel/

Reserved for the Cyberdeck Control Panel, the maintenance app. Glanceable field readings belong to the [Field Dashboard](../dashboard/README.md).

The panel will provide:

- update
- repair
- backup
- drive health
- move `/library`
- restart Nomad
- theme selection: Daybreak or Nightwatch
- automatic day/night switching, by location or by set times
- red night-vision mode and high-contrast sunlight mode
- the low-power/solar mode toggle
- the ROCm or CUDA install, for hardware that skipped it in Welcome or showed up later
- a support-the-creator link (Cash App, Venmo, and X Money via @VeteranPrepper, matching the [README](../README.md))

The language and UI toolkit are not chosen yet. This directory has no application source, no desktop entry, and no build file.

Requirements: [docs/SPEC.md](../docs/SPEC.md), sections 12, 13, and 14.
