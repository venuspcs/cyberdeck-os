# control-panel/

Reserved for the Cyberdeck Control Panel.

The panel will provide:

- update
- repair
- backup
- drive health
- move `/library`
- restart Nomad
- a support-the-creator link (Cash App, Venmo, and X Money via @VeteranPrepper, matching the [README](../README.md))

The language and UI toolkit are not chosen yet. This directory has no application source, no desktop entry, and no build file.

Requirements: [docs/SPEC.md](../docs/SPEC.md), section 12.
